# 📋 Спецификация проекта Adhan (Rust)

## 1. Общая информация
- **Название проекта:** Adhan
- **Автор:** Oruc Qafarov
- **Лицензия:** MIT
- **Исходный прототип:** OrrClockLinux (Python/Kivy)
- **Целевой язык:** Rust
- **Целевая ОС:** Arch Linux (Wayland), Windows, мобильные платформы (планируется)
- **Дистрибутив:** Flatpak (Linux), возможно AppImage; отдельные сборки для Windows и мобильных

## 2. Назначение приложения
Приложение для отображения текущего времени и времён семикратной молитвы (namaz/adhan) с звуковыми и визуальными уведомлениями.

## 3. Внешний вид (по скриншоту главного окна)

### Основное окно
- **Заголовок окна:** `Adhan`
- **Оформление:** тёмная тема, чёрный фон (`#000000`)
- **Корневой контейнер:** только `GridLayout` (по правилам, `BoxLayout` не используется)
- **Размер окна по умолчанию:** 715×1000 px (переносится из прототипа)

### Верхняя часть — часы
- Большие цифровые часы в семисегментном стиле (шрифт DSEG7)
- Цвет цифр: зелёный (по умолчанию, тема `lime`)
- Мигающее двоеточие каждые 0.5 сек
- Пример: `04:04`

### Дата
- Строка под часами, разделена тонкими линиями
- Формат: хиджрская дата / месяц / день - неделя - григорианская дата
- Пример: `1448/VI/6 - 1 - 16/XI/2026`
- Цвет: жёлтый/золотистый

### Центральная часть — время до следующей молитвы
- Иконка мечети слева (цвет темы, например тёмно-жёлтый)
- Большие красные цифры времени до следующей молитвы (например `01:49`)
- Иконка колокольчика/уведомления справа (цвет темы)
- Фон: чёрный

### Нижняя часть — таблица времён молитв (7 молитв)
Список из 7 строк, каждая с названием молитвы на азербайджанском и временем:

| Название (az) | Перевод | Пример времени |
|---------------|---------|----------------|
| Təhəccüd | Полночь / Тахаджджд | `--:--` |
| İmsak | Иmsak (начало поста) | `05:54` |
| Günəş | Восход солнца | `07:22` |
| Günorta | Полдень | `12:30` |
| İkindi | Послеполдень | `15:06` |
| Axşam | Закат | `17:29` |
| Gecə | Ночь | `18:51` |

- Названия молитв отображаются цветом выбранной темы (зелёный, жёлтый, серый и т.д.)
- Время молитв — семисегментный шрифт, цвет по теме (часто тёмный/серый для неактивных, яркий для текущей/следующей)
- Разделитель между названием и временем: тире/линия `-------`

### Ориентация экрана
- Портретная (`height > width * 1.2`)
- Ландшафтная (`width > height * 1.2`)
- Квадратная (иное)
- При смене ориентации перестраивается layout (только GridLayout)

## 4. Цветовые темы
Доступные цвета (по `rules.md`):

| Код | RGBA | Название |
|-----|------|----------|
| white | (1,1,1,1) | Белый |
| black | (0,0,0,1) | Чёрный |
| red | (1,0,0,1) | Красный |
| lime | (0,1,0,1) | Зелёный (по умолчанию) |
| aqua | (0,1,1,1) | Голубой |
| blue | (0,0,1,1) | Синий |
| yellow | (1,1,0,1) | Жёлтый |
| magenta | (1,0,1,1) | Фиолетовый |
| gray | (3,3,3,1) | Серый |

Фон окна, цвет текста, цвет иконок подстраиваются под тему.

## 5. Время молитв (7 молитв)
Список молитв (по `rules.md`):
1. Midnight — Təhəccüd
2. Fajr — İmsak
3. Sunrise — Günəş
4. Dhuhr — Günorta
5. Asr — İkindi
6. Maghrib — Axşam
7. Isha — Gecə

- Город по умолчанию: **Baku**, страна **AZ**
- Метод расчёта: 13 (Азербайджан)
- Источник данных: API `api.aladhan.com` (или совместимый)
- Кэш в SQLite: сегодня и завтра, валидность 30 дней
- Автообновление при отсутствии данных: каждые 15 секунд до появления валидных
- Обновление в полночь: пересчёт на новый день

## 6. Хиджрская дата
- **Решение пользователя:** дата хиджры планируется к **удалению** из текущей версии. Не реализовывать в начале.
- Оставляется как возможное будущее расширение.

## 7. Уведомления
Типы уведомлений (по времени до молитвы):
- 60 минут
- 45 минут
- 30 минут
- 15 минут

Режимы:
- **Без звука:** только визуальные изменения (мигание текста, иконок)
- **Со звуком:** визуал + звуковой файл

Настройки звука (выбираются в настройках):
- Вкл/выкл звука полностью
- Выбор звукового файла для каждого времени уведомления отдельно
- Выбор муэдзина (файла азана) из списка

Муэдзины (по `rules.md`):
1. Noname Muezzin (Adhan from Mihr.Com) — AdhanMihrCom.mp3
2. Noname Muezzin (Slow Adhan) — Adhan01.mp3
3. Noname Muezzin (Old Adhan) — AdhanOld.mp3
4. Ahmed Al Nufais — AdhanAhmedAlNufais.mp3
5. Mansour Al Zahrani — AdhanMansourAlZahrani.mp3
6. Mehdi Yarrahi Fajr — AdhanMehdiYarrahiFajr.mp3
7. Mishary Rashid Alafasy — AdhanMisharyRashidAlafasy.mp3
8. Mishary Rashid Alafasy (Fajr Adhan) — AdhanMisharyRashidAlafasyFajr.mp3

Анимации уведомлений:
- Мигание часов (прозрачность 1.0 ↔ 0.0 каждые 0.5 сек, длится 1 минута)
- Мигание иконок молитв
- Мигание времени до следующей молитвы
- Мигание названия следующей молитвы в списке (жёлтый текст)
- Клик по главному окну останавливает воспроизведение звука

## 8. Настройки
- Öffnen по двойному тапу на главное окно
- Изменения применяются **только после нажатия «Сохранить»**
- Кнопка «Отмена» возвращает исходные значения
- Настройки сохраняются в SQLite (`data/settings.db`)

Настройки include:
- Цветовая тема (8 цветов)
- Город и страна для времён молитв
- Метод расчёта молитв
- Вкл/выкл уведомлений (визуал/звук)
- Выбор звука для каждого времени (15/30/45/60 мин)
- Выбор муэдзина
- Вкл/выкл логирования в файл
- Размер и позиция главного окна (запоминаются)
- Размер и позиция окна настроек (запоминаются)

## 9. Логирование
- Папка `logs/`
- Логи Kivy → заменяются на `tracing` в Rust
- Ротация: максимум 10 файлов, максимум 5 МБ каждый
- Логирование в файл по умолчанию выключено, включается в настройках

## 10. База данных
SQLite (`data/settings.db`), таблицы:
1. `settings` — ключ-значение (цвет, город, звук и т.д.)
2. `window_settings` — размер и позиция главного окна
3. `settings_window_settings` — размер и позиция окна настроек
4. `prayer_times` — кэш времён молитв (date, 7 времён, created_at)
5. (Опционально) `hijri_dates` — если لاحقاً вернём хиджру

## 11. Технические ограничения и правила
- Nunca не использовать `BoxLayout`, только `GridLayout`
- Комментарии к коду на русском
- Бизнес-логика отделена от UI
- Изменения в настройки применяются после нажатия «Сохранить»
- ОС разработки: Arch Linux, графический сервер: Wayland
- Flatpak/AppImage/Docker artefacts класть в папку `target/`

## 12. Аудио
- Плеер: нативный Rust (например, `rodio`)
- Форматы: MP3
- Воспроизведение в отдельном потоке, не блокируя GUI
- Глобальная блокировка для предотвращения overlaps звука
- Звуковые файлы лежат в `audio/adhan/`, `audio/notice/` и т.д.
